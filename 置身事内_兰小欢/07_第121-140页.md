# 《置身事内：中国政府与经济发展》读书笔记

## 前言

- 核心观点：中国政府不仅影响“蛋糕”的分配，也参与“蛋糕”的生产，因此不能脱离政府谈经济。
- 方法：避免用舶来理论先入为主，主张“同情的理解”，先了解现象再作判断。
- 本书特点：脱胎于课程讲义，剔除技术细节，用通俗语言讲述核心概念；注重描述“是什么”和“为什么”，涉及“怎么办”时解释当前政策和改革。
- 分析主角：以中国政府为分析对象，旨在搭建西方理论与中国现实之间的桥梁，帮助读者读懂国家政经大事。
- 地方政府是经济发展中的关键一环，事务繁杂，自主权力很大。

## 上篇：微观机制

### 第一章 地方政府的权力与事务

#### 1.1 行政体系概况

- **五级政府体系**：中央—省—市—县区—乡镇，由历史上的“中央—省—郡县”演变而来。
- **“以市管县”体制**：1983年起全面推行，多数“地区”改为地级市。
- **行政层级复杂性**：省会城市与一般地级市政治地位和经济资源不同；县级市、县、市辖区在土地和经济事务上权力差异（县级市>县>一般市辖区）。
- **条块分割**：从上到下的部门垂直关系称“条条”，横向行政区划为“块块”。大多数地方部门同时接受双重重领导，通常“条条”是业务关系，“块块”是领导关系（因地方党委政府决定人事任免）。
- **层层复制**：中央的主要政治架构（党委、政府、人大、政协等）在省、市、县三级完全复制（“四套班子”）。
- **决策机制**：尽量在能达成共识的最低层级解决问题；跨部门事务设分管领导或“领导小组”协调推进。
- **人事制度**：官员必须学习和贯彻统一的意识形态；由上级任命；地方主官需在多地轮换任职。三大特点延续至今，源于古代官僚体系。

#### 1.2 事权划分三大原则

##### 1.2.1 外部性与受益范围原则

- **外部性**：个人行为影响他人（正外部性如打疫苗，负外部性如抽烟）。行政区划应与政策影响范围一致。
- **规模经济**：公共物品（如公园）使用人数越多，人均成本越低。行政区域需平衡规模经济与物理距离，划分层级。
- **示例**：小学无外部性，地方自主决定；跨市污染需省协调；跨省污染需中央协调；国防全部由中央负担；教材编制由中央主导（外部性极强，形成国民意识）。
- **应用**：理解中央与地方分工（国防vs.中小学教育）；行政区划调整（撤县设区、省直管县等）。

##### 1.2.2 信息复杂性原则

- **信息优势决定权威**：“山高皇帝远”说明信息不通则中央难管控地方。拥有更低成本获取信息的一方具决策优势。
- **形式权威与实际权威**：上级有名义最终决定权（形式权威），下级因掌握具体信息而拥有实际权威。有效管理需平衡二者。
- **信息不对称的影响**：下级可能变通执行或消极应对（“县官不如现管”、“上有政策，下有对策”）。古代官与吏的区别（吏长期任职，实际权力大）。
- **技术手段**：文山会海、公文制度（15种公文）、会议制度是信息传递和权力运作的必要载体。
- **信息扭曲**：GDP数据层层加码、注水；“挤水分”现象；监督机制受信息制约（如土地督察“驻地效应”；水污染监测数据直报但存在地方政府选择性减排）。

##### 1.2.3 激励相容原则

- **定义**：一方想做的事，另一方既有意愿也有能力做好。
- **垂直管理**：适用于专业性强、标准化程度高的部门（如海关），但可能出现激励不相容（如工商系统垂管后当地政府监督约束无力，后恢复分级管理）。
- **双重管理**：当上下级利益冲突时，需明确主要领导，尽量使评价、奖惩、工作内容的上级同一。
- **激励相容要求**：给地方放权，与地方分享发展成果；既要激励地方努力，也要约束地方不要搞砸或努力过头。效果和代价需匹配。
- **属地管理**：以行政区划为权责边界，谁主管谁负责。兼顾公共服务边界和信息优势。
- **制度建设**：权力和资源配置制度化，形成明确预期。外部竞争（要素自由流动、“用脚投票”）可约束地方政府。
- **三大原则共同主题**：处理不同群体的利益差别与冲突。同时需要共同价值观教育（历史教育、国家观念）来消解矛盾。

#### 1.3 招商引资

- 地方政府深度融入经济发展，招商引资是核心任务。
- **手段**：建设工业园区（“七通一平”）、金融支持（政府投资平台入股、协调银行贷款）、法律和政策协助、研发和出口补贴、税收优惠（如“三免三减半”）、个人所得税返还、解决子女入学和就医、招工服务、人才补贴等。
- **生产要素干预**：土地、资金（国有银行、投融资平台）、劳动力（户口、公共服务）、科技投入（公立大学、科研院所）。
- **混合经济**：政府及附属机构深度参与大部分生产和分配环节。

### 第二章 财税与政府行为

#### 2.1 分税制改革

- **背景**：1980-1993年实行财政包干制（“分灶吃饭”），激励了地方政府发展经济，但导致“两个比重”不断下降（中央财政收入占全国比重、预算总收入占GDP比重）。
- **弊端**：中央财政虚弱，宏观调控能力不足；地方预算外收入膨胀（“第二财政”）。
- **1994年分税制改革**：
  - 划分中央税、地方税、共享税；分设国税、地税两套机构（后合并）。
  - 增值税成为共享税（中央75%，地方25%），设立税收返还保基数。
  - 企业所得税后改为共享税（中央60%，地方40%），亦设返还基数。
  - 克服地方阻力（如广东谈判），1993年基数导致地方突击征税。
- **效果**：中央收入占比从22%升至55%并稳定；增强了国家宏观调控能力；但根本上改变了地方政府发展经济的模式。

#### 2.2 土地财政

- **产生原因**：分税制后地方财权上收，事权不变，发展经济需额外资金。1998年住房市场化改革、2002年招拍挂制度推行，土地价值飙升。
- **模式**：地方政府通过征地（农地转为国有建设用地）获得土地垄断权；低价供应工业用地招商引资，高价供应商住用地获得土地出让收入。
- **收入构成**：土地转让收入（土地使用权出让金）+ 土地相关税收（土地增值税、城镇土地使用税、耕地占用税、契税，以及房地产相关增值税、企业所得税）。2018年合计占地方公共预算收入89%，成为“第二财政”。
- **实质**：“房地产财政”。工业用地大面积低价出让，商住用地高价出让，房价地价飞涨。
- **作用**：为城市化和工业化提供了重要资金来源。

#### 2.3 转移支付与基层财政

- **问题**：分税制后中央集中收入，地方支出责任不减，导致纵向不平衡（基层财政困难）和横向不平衡（地区差距）。
- **基层困境**：“财权层层上收，事权层层下压”，县级财政沦为“讨饭财政”。农村税费改革取消农业税，进一步减少基层收入。
- **中央应对**：
  - 大规模转移支付（一般性转移支付和专项转移支付），超过80%流向中西部。
  - 2005年“三奖一补”激励地方精简机构和增收。
  - “乡财县管”、“省直管县”改革（源自浙江经验），试图将五级财政扁平化为三级。
  - 但省直管县在其他省份面临困难：省管幅度太大致监管不足；县市竞争造成“孤岛效应”。
- **效果**：省际人均财政支出趋于均等，但县级差距依然显著；专项转移支付可能加剧不平等。

### 第三章 政府投融资与债务

#### 3.1 土地金融与城投公司

- **概念**：土地财政叠加杠杆即“土地金融”。地方政府以土地未来收益为抵押，通过城投公司借款。
- **城投公司**：地方政府设立的全资国企，用于规避法律限制（不能直接从银行贷款，2015年前不能发债）进行融资和投资。典型模式：国家开发银行1998年与安徽芜湖合作创立。
- **运作模式**：
  - 政府注入土地使用权；城投公司进行一级开发（拆迁、整理，将“生地”变“熟地”）；政府回购后招拍挂出让；城投公司用土地出让收益和补贴还款。
  - 实体案例：成都文旅集团（宽窄巷子，投入6.5亿，依赖政府补贴）、兆润集团（苏州工业园区土地一级开发）、合肥建投（支持京东方）。
  - 政企合作新模式：PPP（如华夏幸福“产城结合”模式，政府购买服务），但社会资本仍以国企为主。
- **特点**：投资规模大、周期长、回报率低，依赖政府隐性担保和土地抵押。

#### 3.2 地方债务风险与治理

- **债务积累**：2008年“4万亿”刺激导致城投公司激增（从3000余家增至8000余家），地方债务快速膨胀。2015-2017年估计总额约四五十万亿元（占GDP五六成），以隐性负债为主。
- **风险特点**：层级越低风险越高（县级负担远高于省级），中西部风险高于东部；主要用于基础设施投资形成资产，但回报率低（平均不到1%），依赖土地收入和补贴还债。
- **治理措施（2010年后）**：
  1. **债务置换**（2015-2019）：用低息长期政府债券替换高息短期城投债/银行贷款，降低利率（从7-8%降至4%左右），延长期限，提升信用。
  2. **融资平台转型**：剥离政府融资功能，打破隐性担保（但转型困难，负债难处理）。
  3. **金融机构监管**：限制资金流入平台，规范影子银行（2018年“资管新规”）。
  4. **问责官员**：终身问责、倒查责任（2018年《地方政府隐性债务问责办法》）。

#### 3.3 官员激励与行为

- **激励机制**：
  - **地方主官**：追求政绩（GDP增长），以晋升为目标。任期短（平均3-4年），倾向于上马大项目，形成“政治-投资周期”（新官上任三把火）。
  - **基层公务员**：晋升希望小（县处级及以上仅占1%，正科升副县概率约1%），更关注收入和福利（与本地财政挂钩）。
  - **精神激励**：使命感、价值观（“不忘初心”、“家国情怀”、“为人民服务”）。
- **后果**：
  - 重投资轻民生、重“看得见”的工程（道路、桥梁）轻“看不见”的工程（地下管网），导致内涝。
  - 城市“摊大饼”扩张，通勤成本高。
  - 过度借债，债务攀升（2016年前调任后不负任内债责）。
- **考核改革**：2013年起“不以GDP论英雄”，2019年《党政领导干部考核工作条例》要求全面考核。
- **人情与业绩**：政绩考核难以完全客观，人情关系有一定作用，但地方竞争一定程度上约束了恣意行事。

#### 3.4 腐败问题

- **特点**：腐败与经济高速增长长期并存。形式随改革阶段变化：80年代“官倒”、90年代国企改革、21世纪土地开发。
- **分类**：
  - **掠夺式腐败**（敲诈勒索、索贿、盗用公款）：随法制完善和技术进步（如电子缴费）已大大减少。
  - **官商勾连式腐败**（共同发财）：短期可与增长并存，但长期扭曲结构（重投资轻消费）、扭曲投资配置、扩大贫富差距、破坏政治生态（塌方式腐败）。
- **反腐运动**：十八大以来高压态势，立案审查大量高官（截至2019年底，县处级及以上15.6万人）。长期看需转变政府职能，简政放权。
- **副作用**：部分官员“为官不为”，中央推出容错机制。

### 第四章 工业化中的政府角色

#### 4.1 案例一：液晶显示面板（京东方）

- **背景**：2008年大陆面板几乎完全依赖进口（进口额500亿美元），日韩台企业通过“晶体会议”操纵价格。
- **京东方发展历程**：
  - 早期5代线（北京）亏损，靠政府救助。
  - 转向股权融资优先：成都4.5代线（政府定增+银团贷款）、合肥6代线（总投资175亿，合肥政府以城投公司兜底定增，暂停地铁）。
  - 合肥6代线建成大陆首条高世代线，突破封锁。
  - 后续扩张（北京8.5代、合肥10.5代等）均采用“地方平台出资+银团贷款”模式。
- **效果**：大陆面板占全球产能近四成，成本大幅下降，带动下游产业崛起；形成产业集群（合肥“芯屏器合”）；合肥GDP十年增3.4倍，进入万亿俱乐部。
- **启示**：政府投资上游产业可打破国际垄断；国内市场规模大，支持本土产业能产生巨大正外部性；规模经济与产业集聚刺激创新（“边做边学”）。

#### 4.2 案例二：光伏产业

- **产业兴衰**：
  - 国际市场爆发（欧洲补贴） → 中国大量企业涌入（尚德、赛维） → 欧美“双反” → 全行业崩塌（2012年） → 国内市场启动（江苏、中央标杆电价补贴） → 重获新生 → 全球主导（产能占80%）。
- **地方政府角色**：天使投资人（无锡政府扶持尚德）、提供土地和贷款（赛维）、推动规模扩张。但也导致重复建设和过度负债。
- **补贴机制**：从德国标杆电价到中国“金太阳工程”、度电补贴。“531新政”（2018）降低补贴，倒逼行业平价上网。
- **中国模式成功原因**：全产业链本地化、规模经济、边干边学、激烈竞争（价格战、成本创新）、内需市场扩大。
- **教训**：产业政策需要退出机制（补贴逐渐退坡）；低效企业破产渠道必须顺畅（如尚德市场化重组受偿率高，赛维行政干预恶果）。
- **核心理念**：“保持竞争”比“重复建设”更重要；创新离不开实践中的学习。

#### 4.3 政府产业引导基金

- **定义**：政府设立的母基金（FOF），将财政资金委托给市场化私募基金（GP），通过带动社会资本投向战略性新兴产业。
- **发展历程**：
  - 2005年政策试点，2008年确立十六字原则（政府引导、市场运作、科学决策、防范风险）。
  - 2014年新《预算法》改革刺激爆发（限制财政补贴，引导基金成为新载体）。
  - 配套条件：2007年《合伙企业法》为有限合伙提供法律保障；资本市场改革（创业板、新三板、科创板）拓宽退出渠道；保险资金等社会资本参与。
- **现状与困难**：
  - 规模庞大（截至2019年到位资金2-4万亿元），头部如国家大基金、深创投。
  - 投向：芯片、新能源汽车、人工智能等战新产业。
  - **体制性困难**：
    - 财政资金保值增值目标 vs 风险投资可能亏损的矛盾。
    - 资金地域属性（招商引资需求） vs 资本无边界矛盾（限制跨区域投资）。
    - “名股实债”增加隐性债务（中央明确禁止）。
    - 社会资本募资难（2018年“资管新规”后）。
    - 管理机构缺乏市场化薪酬，人才激励不足。
- **意义**：市场化方式使用财政资金的新探索，也是招商引资和产业政策的新工具。

### 经济发展阶段与改革方向

- **发展阶段变化**：从农业转工业的效率提升转向技术升级；土地要素市场化配置提上议程（2020年要素市场化配置意见，探索跨省指标交易）。
- **政府角色转变**：从生产投资型政府向服务型政府转型；简政放权、深化放管服改革。
- **债务与风险**：地方债务总体风险可控（占GDP六成，低于美日），但结构性问题严重（县级、中西部）；化解债务需深化改革官员考核、约束投资冲动。
