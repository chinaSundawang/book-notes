## 阿尔弗雷德·阿德勒与个体心理学

### 阿德勒生平与理论创立

- 童年经历：患有佝偻病和肺炎，身体矮小丑陋，在兄弟间感到自卑，因此立志成为医生与死亡斗争
- 凭借毅力成功，1895年获维也纳大学医学博士学位，成为医生，后转向神经病学和精神病学领域
- 阅读弗洛伊德《梦的解析》后赞同其观点，与弗洛伊德建立友谊并加入心理分析社团，后因观点不合分裂
- 与同事创立“自由心理分析研究学会”，将自己的研究命名为**个体心理学**，强调个性的唯一性和不可分割性
- 一战期间担任军医，战后在维也纳从事儿童心理学辅导，声名大振
- 1926年抵达美国，受聘于哥伦比亚大学；1932年成为长岛医学院教授；1935年创办国际个体心理学学刊
- 1937年因劳累过度心脏病突发去世
- 留下大量著作，为后世研究提供了便利
- 理论经事实证明对社会有贡献和价值，有助于营造人人平等的环境，强调人格和尊严的平等，并鼓励人们发挥潜能

### 人生意义的基本观点

- 人类体验事物通常从自身角度出发，事物的意义与人类相关（如“木头”“石头”都是人类生活的要素）
- 脱离事物本身的意义而孤立思考环境，自我封闭，于己于人皆无益处；人的存在不能脱离生活的现实本义
- 体验现实应将其放大到人生和生命存在的高度来解读意义和价值，但总有遗憾和缺陷，不可能永远正确
- 人生意义的问题常被回避，只有在遇到困难和挫折时才会被提出；人生平坦顺利的人大多不会思考这个问题
- 每个人在行动中都在诠释人生的意义，这种意义与其观点、态度、举止、表达、癖好、志向、习惯和性格特征表现一致
- *“我是这样，宇宙是那样”* 是个人对世界和自身的总结，影响其行为，是对自己和所理解的人生意义的一种判定
- 对人生意义的解释不一定全部正确，但每个人都会有自己的解读，并通过行动体现出来
- 绝对意义上的正确真理无人知晓，任何相对有效的解读不能判定为绝对错误
- 人生意义的全部内容存在于绝对真理与绝对错误这两个极端之间
- 可以分辨不同解读的优劣：较好的解读大同小异，劣质的解读难掩其伪

### 三大制约与三大人生问题

- 人生面临的所有困难或问题都源自于生活中受到的三大制约，这些制约构成人生和现实的内容
- **第一种制约**：人类必须生活在地球上，与地球上的资源共存，需善待地球并保持身心健康
- **第二种制约**：每个人都必须与周围其他人相互关联，人类个体的弱点和局限决定了一个人无法单独达成目标，必须与他人团结合作才能生存并为社会作出贡献
- **第三种制约**：人类分为男女两性，需处理爱情与婚姻（即两性关系与人类延续）
- 由三种制约引申出三个问题：
  - 如何利用有限资源让人类永存
  - 如何在人群中定位以实现合作
  - 如何调整自我以适应两性关系
- 个体心理学将所有人类问题归为三类：**职业、交际和两性问题**；人们对生活意义的理解体现在对这三类问题的回应上

### 人生意义的真正标志：普遍性与贡献

- 对比两种人生态度：一种人视活着为危险，自我封闭，导致失败；另一种人视活着为创造过程，积极面对困难，关注他人并贡献社会
- > 真正的人生是懂得关注他人、让自己成为社会大家庭中的一员，并积极地为人类的福祉作贡献。
- 人生的意义在于与他人交往并为其作出贡献；真正的意义具有普遍性，可以与他人共享；自我中心的意义是虚无的
- 精神病人、罪犯、酗酒者、问题少年等失败者，是因为缺乏社会兴趣和安全感，在处理三大问题时从不寻求他人帮助，认为人生的意义是以自我为中心
- 罪犯通过武器获得虚假的强势感，但武器并不能真正提高其价值；这种自我满足对他人毫无意义
- 自我意义没有任何意义；真正的意义必须从与人交往中体现；如果不明白成功和卓越建立在为他人作贡献的基础上，就会产生错误
- 所有人生意义的真正标志是普遍性，即能够与他人共享并贡献于社会
- 人生的意义在于对整体作出贡献，面对困难时毫不退缩，其本质是关注他人并与他人合作，且解决问题不以伤害他人为基础
- 在爱情和婚姻中，若想使对方幸福，便会极力表现自我并投入关心；反之若只顾自己，则会变得趾高气扬、令人厌恶
- 祖先留给后人的遗产（土地、道路、建筑、哲学、科学、艺术等）都是对人类贡献的体现，印证人生的真谛在于奉献与合作
- 拒绝与他人合作、只想逃避生活的人没有给人类留下有益的东西；地球给出的判语是：你一无是处，人类不需要你

### 童年早期与人生意义的形成

- 从出生起，人就开始探索“生活的意义”；儿童早期（前五年）形成固定的行为模式，并建立对自己和社会的基本概念
- 儿童对生活意义的理解需要他人诠释，因为儿童时期尚不了解社会经验
- 即使认知偏离正轨，儿童也很难自行改变，只有在压力或专业心理学指导下才能修正
- **三种容易误导的儿童类型**：
  - **身体残缺的儿童**：容易以自我为中心，除非有人引导其关注他人，否则会因嘲笑或同情而自卑；但克服困难能激发内在潜能，人类的伟大成就往往来自对困难的克服
  - **被过于宠爱的儿童**：曲解生活的意义，认为自己的愿望就是法律，习惯只索取不付出，缺乏自立和合作意识；表面迎合实则伺机攻击
  - **受人冷落的儿童**：不知道关心和互助的概念，高估困难程度，从不寻求他人帮助，认为社会是冷漠的，不信任他人
- 母亲的首要任务是让孩子一出生就感受到对自己的依赖，然后逐步将这种感情扩展到周围事物；如果母亲未能完成，孩子很难对社会产生兴趣并形成合作与互助的情感
- 完全被忽视的儿童（如孤儿或私生子）缺乏对人的依赖感，难以与人沟通
- 儿童可能通过制造麻烦（如尿床）来获得父母关注，这是一种获得安全感的策略；这种行为通常源于压力（如弟弟妹妹出生后关注减少）
- 让年龄较大的孩子自愿参与照顾弟妹，可以培养合作精神、责任感

### 早期记忆与性格分析

- 记忆是理解人生意义的关键，它提醒我们希望、逃避和人生经验的积累
- **早期记忆**是了解个体生活方式和生活态度至关重要的线索，因为它包含最初印象和主观观点的起点
- 早期记忆的真实性不重要，重要的是它对未来生活的影响
- 例子：一个女孩早期记忆被咖啡壶烫伤，导致她日后夸大危险、觉得他人关心不够
- 例子：一个人三岁时从婴儿车摔下，常做世界末日的梦，说明早期记忆影响其对人生意义的认知
- 早期记忆中的情境往往能揭示个体的人际关系模式，例如害怕独自面对黑暗或异性，可能预示成年后对社交和亲密关系的回避
- 通过分析早期记忆，可以推断个体性格倾向和生活风格：依赖感、对弱者的轻松感或对异性的恐惧
- 喜欢与人相处并不一定代表真正对他人有兴趣，可能只是为了让自己不再孤单（如一个女孩早期记忆显示喜欢群体合作但害怕独处，说明独立性差）
- 早期记忆可以揭示人的性格特点，如独立性差、依赖他人等
- 案例：一个女孩回忆全家福拍照时弟弟手里有红球而她没有，她因此故意不笑，反映对公平的敏感、视觉型特质以及可能的社会适应困难
- 案例：另一女孩回忆三岁时在地窖尝苹果酒并打翻酒桶，预示勇敢冒险的性格和从错误中学习的倾向
- 治疗心理问题时，不应责怪患者或单纯依赖药物，而应通过早期记忆找到其兴趣点，改变错误观念

### 心灵与肉体的相互影响

- 个体心理学认为心灵和肉体是人生中的两种表现形式，应从整体理解它们的关系
- **精神因素的核心力量**在于具备预知能力并指导自身的发展方向；精神为肉体的运动指明方向
- 精神是运动的主导因素，但肉体也会影响精神；只有当身体条件允许时，精神才能真正发挥支配作用
- 人类的活动范围远大于其他动物，大脑会越来越有预见性，奋斗的目的性越来越强，以改善自身处境
- 每个人的所有局部动作背后都有一个单一的、包含一切部分运动的整体动作，其根本目标是**寻求安全感**，即克服所有困难并将自己从中解脱出来
- 任何动作都有意义；心理学的研究目的是找出人表现出的各种动作所代表的意义，探寻其最终目的
- 偷盗行为的目的是通过获得更多财富来获得安全感，其根源是贫穷或匮乏感
- 人在四五岁之前形成统一的思维和精神与肉体的合作，六岁前人格基本定型，包括人生意义、追求目标、处事态度和情感秉性
- 心理上的错误目标选择会导致行动上的错误
- **补偿现象**：身体缺陷可能促使个体在相关领域发展出更强的能力（如弱视儿童更关注视觉世界，最终视觉分辨力和审美能力优于常人）
- 左撇子孩子被强制改用右手后，通过努力练习同样能变得灵活
- 只有想将自己融入整体、不只关注自己的孩子，才会慢慢弥补自身的缺陷
- 如果一个人将目标定位于身体之外的其他方面，就会培养、训练自己达到指定的目标，认为困难是成功之路上必须清扫的阻碍
- 遗传的缺陷可以被转变（如肾管缺陷家族的孩子可能通过训练克服遗尿症）
- 父母对孩子某种行为的过度关注，会给孩子提供表现自己的机会；孩子会通过这种表现来表明自己的意志
- 尿床等方式表达自己的孩子，通常是因为受到压力，比如曾经很受关注后来被忽略
- 精神对身体有影响：精神可能引起病症并影响整个身体的发育
- 消极的精神状态可能导致身体发育的萎缩；身体的状况也会反过来影响精神
- 由精神引起的身体不适常见于未能找到克服身体障碍的方法的人
- 情绪变化（如愤怒、焦虑）引起身体反应：脸色变化、心跳加速、冒冷汗、呼吸紧促、颤抖等
- 精神紧张影响自主神经系统和非自主神经系统，导致无意识动作（如敲桌子、咬嘴唇、撕纸等）
- 一个人的人生态度和情感会对身体发育造成持续性影响；勇敢的人体型较大、肌肉结实、站姿挺拔
- 精神对大脑有影响作用：大脑左半球受损后，其他部分可通过训练弥补功能；个体心理学主张通过教育开发大脑

### 自卑感与自卑情结

- **自卑心理**是个体心理学的重大发现之一，但常被误用或不被充分理解
- 简单地告诉病人自卑没有益处反而会加重其自卑感；正确做法是找到其人生态度的缺点并在缺乏勇气时给予鼓励
- 神经官能症患者都有自卑感，但与其他患者的区分在于对生活的失望感和努力活动受限制的程度
- 自高自大的人往往隐藏着自卑感（如身高不足者垫脚或挺直身体）
- 自卑感的表现多种多样：例子中三个孩子在狮子笼前的不同反应（害怕、掩饰、逞强）都是由人生态度决定的
- 每个人心中都有不同程度的自卑感，因为我们都想让自己的生活变得更好一些
- 如果充满信心，用简单实际的方法去改变生活，自卑感可以慢慢消除
- 如果失去自信，寻求自我安慰或强迫自己认为有优越感，不但无法消除自卑感，反而会越来越强烈，导致压力越来越大
- **自卑情结的定义**：当一个人遇到他无法解决的问题却深信自己能够解决时，就会表现出自卑情结
- 自卑的表现包括愤慨、泪水、歉意，以及通过追求一种优越感来释放压力，但无助于解决问题
- 陷入自卑的人会搁置真正的问题，从琐碎小事中寻求优越感，并约束自己以避免失败
- 广场恐惧症是自卑的一种表现；自杀是面对困难时最大的退缩表现，但自杀者也在争取一种优越感（常把责任推给别人）
- 眼泪和抱怨被称为“水性的力量”，是破坏和谐、支配他人的有效手段
- 自卑心理有两种表面表现：一种显露在外（爱哭、胆小、有负罪感），另一种喜欢吹嘘、自高自大（行动上不承认自卑）
- 恋母情结是神经官能症的一种特殊表现，源于缺乏安全感和过度依赖家庭
- 神经官能症患者的行为特征之一是行为受限（如结巴、差生、失眠、性功能障碍等）
- 自卑感并非只有坏处，它也能促使人改变自身处境；人类文化的基础是拥有自卑感，促使科学进步和生存环境改善
- 人类是地球上最脆弱的群体，但通过合作群居可以超越其他动物

### 对优越感的追求

- 对优越感的追求具有唯一性，取决于个人划定的人生意义，体现在人生态度中，如同自创的美妙曲子贯穿一生
- 人在四五岁时就已形成对人生意义的理解，对优越感的追求是一种内在动力，不是静止的点
- 职业目标（如医生、老师）往往源于对自卑感的补偿，需要结合其具体素养和动机来理解
  - 医生：早期经历死亡事件可能激发其学医以对抗死亡、弥补不安全感
  - 老师：素质修养低的老师可能通过与弱小者相处来获得优越感
- 争取优越感的过程并非固定不变；身体和精神越健康，在面对困难时越能找到最佳办法；神经官能症患者则只认定一个目标，排斥其他可能性
- 所有行为都有一个共同目标：希望成为人上之人（如孩子说“我要成为上帝”，疯子说“我是拿破仑”）
- 一个人确定所追求的目标后，人生态度和所有行动都会与此目标一致；指出行动错误无效，因为目标决定了行动
- 案例：懒惰的学生为了吸引老师注意而保持懒惰；孩子宁可愚笨也不愿像哥哥那样鲁莽，认为愚笨可以避免麻烦
- 许多表面缺陷或病症（如装笨、数学成绩差、头疼）实际上是个人为了达到某种目的而采取的手段（逃避过高要求、控制环境等）
- 单纯消除病症无法根除问题；治疗需要深入探究症状背后的目的，并引导其改变目标
- 阿德勒以自己爬梯子坐到黑板顶端为例，说明如果不理解行为背后的目的，旁观者只会认为行为荒谬
- 改变个体的目标比直接改变行为更有效；目标一旦改变，思维和态度会自然调整，旧的行为随之改变

### 合作精神与社会兴趣

- **合作精神**是解决人生各种问题的基础；人生的意义在于奉献，勇敢面对困难才能取得成功
- 培养合作精神是防止神经性疾病产生的唯一方法；让孩子学会与人合作，并在日常生活或游戏中处理同伴关系，对成长至关重要
- 缺乏合作精神会导致自私、缺乏责任感和独立性，难以面对挫折和困难
- 不能指责成年人在童年时犯的错，而应帮助他们纠正；不能要求没有合作训练的人灵活应对合作问题
- 具有自立合作精神的人会认为人生需要自己主宰、能够处理好自己的事，并主动参与推陈出新的工作，从而推动人类文明永不停息
- 个体心理学主张通过观察四五岁儿童的认知、人生态度和世界观，从中发现他们生活中的障碍并帮助克服
- 失败的人共同特征是合作能力差；心理学可以定义为研究合作缺失程度的学科
- 人生态度贯穿一生，思想和情感与之保持一致；只有改变人生态度才能真正改变情感问题
- 教育和治疗不能针对单一症状，必须了解个体对人生的错误思想、错误解读、自身经历及对环境的错误看法
- 理解一个人的最佳方法是观察他的合作能力
- 对优越感的追求只有为了他人利益和社会发展而奋斗的人才能顺利解决生活难题；人类对价值和成功的判断以合作为基础
- 神经官能症患者和罪犯也懂得社会情感，但他们缺乏正常人的勇气，自卑心理让他们觉得无法合作，从而逃避现实问题
- 治疗实质上是对合作能力的运用和检验；只有真正关心他人并设身处地为其着想，才能做好工作
- 帮助病人的唯一有效方法是引导他们将注意力转向他人

### 梦与记忆

- 梦和想象在压力较小的睡眠中能真实反映人的性格，有助于了解自己
- 记忆具有平衡情绪的功能：沮丧时想起挫折，忧郁时记忆悲伤；愉快时记忆快乐

### 儿童心理问题与教育

### 个体心理学的核心方法与原则

- 个体心理学不采用“正转移和负转移”的分类，与其他心理学学派不同
- 纵容娇惯的病人会增强其控制欲，而稍加怠慢则导致敌对
- 治疗时需与病人合作，一起发现错误，使其对自己和他人都有利
- 不应让病人产生“转移”、表现出权威姿态、或让病人继续依赖他人、逃避责任
- 个体心理学的研究方法类似考古学家，从细枝末节（如走路、打招呼、微笑等）中寻找线索，逐步拼凑出人的整体性格
- 每一次仓促的决定或评价都可能出错，但可以通过后来的大量表现进行纠正；只有将一种表现放在整体中才能确定其意义
- 性格是固定不变的，就像三角形无论如何放置或观察，形状始终不变；不能从行为举止的单个方面判定整体情况，必须从全部表现中观察
- 训练推测力是理解他人性格的重要方法，但需谨慎验证，避免武断下结论
- 心理学应关注人生态度问题，而非简单的生理反应测试
- 个体心理学主张通过观察四五岁儿童的认知、人生态度和世界观，从中发现他们生活中的障碍并帮助克服
